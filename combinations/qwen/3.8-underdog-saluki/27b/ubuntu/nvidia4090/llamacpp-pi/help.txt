WHY THIS MODEL (Underdog Saluki 27B, 2-bit)
  Qwen3.8-27B as an IQ2-mix GGUF by Underdog (ConwayResearch), "tuned to keep
  tool calling intact", with the base model's MTP head grafted on by Kujira
  (nothing re-quantised or trained). The author's figures, not reproduced
  here: tool calling 88 against 84 for the full model (120 tasks), SWE-bench
  Verified 30 against 33 (50 issues), AIME 2025 79 against 97.

MTP / SPECULATIVE DECODING
  The MTP head is inside the GGUF (blk.64.*, Q8_0 and F32), so the launcher
  uses --spec-type draft-mtp with --spec-draft-n-max 4 and no sidecar. "MTP
  head missing" at install is expected. The author measured acceptance of
  62-96% at temperature 0 with a draft depth of 2; ours is temperature 1.0 and
  depth 4, so acceptance is not known. Confirm the head is live: grep the
  server log for "creating MTP draft context" and "draft acceptance".

THE PIN
  The install fetches the repository commit named in config.sh and refuses a
  file whose sha256 differs from the one the card prints. Both uploads were a
  day old when this was written.

GOTCHA: THINKING MODE AND max_tokens
  Reasoning is billed against max_tokens; a small max_tokens returns an empty
  answer with finish_reason "length". Give agents a generous max_tokens.

SECURITY
  HOST defaults to 127.0.0.1 and there is NO authentication.
