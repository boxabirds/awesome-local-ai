# Vidi reference stack: Claude Code + Sonnet 5.5

A second frontier-model reference, beside [Opus 5.5](../opus-5.5/): Claude Code driving Claude Sonnet 5.5
(released 30 September 2026) through the Vidi canvas scope (stories 1–5 and 7–12). It runs exactly as the
Opus v2 runs did: the same harness, sandbox, prompts, held-out suite and client; only the model differs.
`stack.env` registers it with `../../install-stack.sh`. The runbook is in
[`benchmarks/vidi/README.md`](../../../vidi/README.md).

Runs: `v2-r1` to `v2-r3`, one after another on the M2 MacBook Air, from 1 October 2026.
