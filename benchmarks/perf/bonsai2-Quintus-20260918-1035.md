## A. Coherence check

Prompt: reverse a linked list, code only, at reasoning effort `medium`.

The effort is set explicitly. Bonsai 2 defaults to `xhigh`, which spends
most of a small token budget reasoning before it answers -- measured
elsewhere in this repo, a 200-token budget returned 731 characters of
reasoning and 9 of content. Left at the default, this check would often
show a reasoning block and no code, and the heuristic below would cry wolf.
Its card states `low` is not supported, so `medium` is the floor.

## D. Context ceiling

Whether a context ALLOCATES, which is what decides the profile table. This
deliberately does not prefill: filling 128k on a Mac at ~50 tok/s prompt
rate would take the better part of an hour per row and measure decode
decay, not whether the context fits.

- ctx **8192**: OK, resident 7350 MiB
- ctx **32768**: OK, resident 7782 MiB
- ctx **65536**: OK, resident 8359 MiB
- ctx **131072**: OK, resident 9511 MiB
- ctx **262144**: OK, resident 11828 MiB

Largest context that loaded: **262144**
