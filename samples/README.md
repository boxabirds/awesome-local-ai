# Samples

Things models installed by this repo actually built, kept as worked examples of
what a local setup produces. **Not maintained software.**

| Sample | Model | Combination |
|---|---|---|
| [`meteor-rush/`](meteor-rush) | Qwen3.8-27B | `qwen/3.8/27b/ubuntu/24GB/llamacpp-opencode` |
| [`meteor-rush-no-thinking/`](meteor-rush-no-thinking) | Qwen3.8-27B | same, with `THINKING=0` |

Both are the same 3D meteor game written end-to-end by the local model through
OpenCode from one prompt, with a single variable changed. See
[`meteor-rush/README.md`](meteor-rush/README.md) for the comparison.
